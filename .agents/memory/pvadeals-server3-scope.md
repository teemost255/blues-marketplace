name: PVADeals Server 3 scope
description: User-selected rental scope for the PVADeals virtual-number provider.
---

Server 3 should match the existing 20-minute virtual-number rental flow. Long-term rentals are out of scope unless the user asks to add them.

**Why:** the user explicitly chose the existing 20-minute rental flow when asked whether to include PVADeals long-term rentals.

**How to apply:** keep the Server 3 customer flow focused on short-term rentals; treat LTR plans as a separate future feature.
