Accounts API Documentation
Fetch delivered accounts from your orders. Use your API key above.

Base URL: https://surepluglogs.com/api/v1/accounts

Endpoints

 List Available Products
GET
https://surepluglogs.com/api/v1/accounts/products?key=YOUR_API_KEY&search=&category=
Parameters

key
Your API key. (Required)
search
Search term to filter products. (Optional)
category
Category ID to filter manual products. (Optional)
Example response

{"status":true,"data":{"catalog":[{"id":1,"provider_product_id":"prod_123","type":"catalog","title":"Instagram Followers","description":"Buy Instagram followers","image":"url","price":0.05,"min_quantity":100,"max_quantity":10000,"stock":50000}],"manual":[{"id":2,"type":"manual","category_id":3,"title":"TikTok Account","description":"Premium TikTok account","image":"url","price":25.00,"stock":15}]},"meta":{"search":null,"category_id":null,"total_catalog":50,"total_manual":30}}

 Advanced Purchase Account
POST
https://surepluglogs.com/api/v1/advanced/purchase-account
Request Body (JSON or Form)

key
Your API key. (Required)
product_type
catalog or manual. (Required)
product_id
Product ID. (Required)
quantity
Quantity (integer >= 1). (Required)
callback_url
URL to POST results to (Optional)
Example request (JSON)

{"key":"YOUR_API_KEY","product_type":"catalog","product_id":123,"quantity":2,"callback_url":"https://yourdomain.com/webhook"}
Example response (success)

{"status":true,"order":{"id":456,"provider_trans_id":"VIACLONE_12345","quantity":2},"vendor":{...},"accounts":[{"id":1,"credentials":"username: user1","created_at":"2024-01-15T10:30:00Z"},{"id":2,"credentials":"username: user2","created_at":"2024-01-15T10:31:00Z"}]}
Possible errors

401
Missing or invalid API key
404
Product not found or inactive
422
Invalid product_type, insufficient balance, or quantity exceeds stock
502
Vendor (provider) purchase failed
Notes

For catalog products, the vendor response is included under the vendor key.
If callback_url is provided, the same response JSON will be POSTed to that URL (best-effort).
User balance is debited immediately upon successful purchase.
